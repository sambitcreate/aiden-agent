# Magenta RealTime 2 model terms

Aiden does not bundle these model files. The user may explicitly download the pinned `google/magenta-realtime-2` revision from Hugging Face for on-device generation.

The model card identifies the weights as Creative Commons Attribution 4.0 (CC BY 4.0) and includes responsible-use guidance. Aiden must present the source, license, expected disk use, local-generation behavior, and sustained power cost before the first download. Redistribution and generated-output use remain subject to the upstream terms.
