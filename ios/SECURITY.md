# Security

Report security issues privately through the sole repository's GitHub security-advisory flow. Do not include device credentials, provider keys, pairing payloads, prompts, filesystem paths, or private logs in a public issue.

The mobile threat model is [`../docs/security/aiden-remote-threat-model.md`](../docs/security/aiden-remote-threat-model.md). Remote Access is off by default, uses per-device revocable credentials, and cannot widen Aiden workspace authority or enable Computer Use.
