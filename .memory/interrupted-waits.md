# Prompts that survive a restart — 2026-10-29

Branch: `claude/project-thread-euhzg4-questions`. Desktop only (Mac and Linux); no Remote protocol change, phones unchanged (same scope as the #599 Resume card).

- `main/services/interrupted-waits-main.ts` keeps one open wait per chat in `interrupted-waits.json` (compact `DataStore`, normalized with `parseAskUserQuestions`, 7-day expiry, at most 100 records). `createInterruptedWaitStore` in `main/services/interrupted-reply.ts` holds the logic and is unit-tested.
- `llm-client.ts` remembers a wait when the ask-user or approval coordinator publishes a prompt, keyed by waitId (several per chat). `interruptedWaitSettled` decides: it is forgotten on any settlement except a host withdrawal while `quitInProgress` is set. `main/index.ts` sets that flag (`llmClient.setQuitInProgress`) in `requestApplicationQuit` before `closeRendererBeforeShutdown` and in `shutdownAndQuit`, and clears it when the quit is called off. A flag set later (at abortAll) fails, because the window closes first and withdraws the cards. A reload or closed window without quitting forgets the wait (review finding: otherwise a crash later in the same run offered a question the reply had moved past).
- Deleting a chat forgets its waits (`releaseChatContext` in chat-application-service-main.ts); expired ones are pruned at launch in the chats handlers.
- `chats:interruptedWaits` returns the waits only when the chat's latest run is interrupted and `askedAt >= run.startedAt`, so Stop or a new message hides it (a later run exists).
- Renderer: `chat-pane.tsx` rebuilds the question as a synthetic prompt (promptId = waitId) with the "restarted" `AskUserQuestionExpiryNotice`; submitting sends `formatRecoveredAskUserQuestionAnswers` as a normal message and then dismisses. Closing the card dismisses and leaves the Resume card. An approval wait only adds its summary to the Resume card. The Resume card waits for the waits query so it never flashes before a question. Answers use the shared `formatAskUserQuestionAnswers` ("Skipped" included).
- Tests: `interrupted-reply.test.ts`, `ask-user-question-coordinator.test.ts`, `tests/e2e/interrupted-question-resume.spec.ts`.
