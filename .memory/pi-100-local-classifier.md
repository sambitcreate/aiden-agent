# Pi 1.0 desktop local classifier

Implemented on `codex/pi-1-local-classifier`, stacked on PR303 (`bffa1c9ec`, including integration53161ba13).

- Custom local OpenAI-compatible providers have an explicit, saved `llamaCppClassifierEnabled` opt-in in More options. Missing/false is off. Handler, config persistence, and portable-config validation reject invalid or hosted/built-in capability flags. Onboarding points to this existing provider control.
- `pi-local-classifier.ts` composes Pi's public `llama-cpp-classify` operation over the global native operation catalog. It uses only saved chat-model IDs, never adds classifier records to chat selectors, and makes no discovery/download/load requests when enabling the preference or constructing inventory.
- Each approved classifier invocation checks current enabled provider/model identity, validates the saved HTTP(S) URL, resolves request-scoped credentials, and rechecks after resolution. Only a terminal `/chat/completions` is stripped by Aiden; Pi strips terminal `/v1`, preserving reverse-proxy prefixes. Caller-supplied model URLs/headers are not authority. Keyless requests never send the chat compatibility auth placeholder. Cancelled requests stop before dispatch; Pi errors remain structured tool errors without a chat fallback.
- The operation facade uses `providerRegistry.models`, so local/custom chat sessions can use independently configured native image providers. Those requests retain their native endpoint/auth resolution. Existing paid-operation approval is unchanged. Local classifier records are accounted as local usage.
- Native iOS/Android `AidenProvider` remains id/label/artwork/models only; remote projection test proves the capability flag does not cross the chat catalog boundary. No protocol revision or native wire change.
- Explicitly out of scope: server/router management, model download/load/unload UI, virtual-model routing and re-routing, unattended Bot/scheduled classifier access. CLI inherits Pi's broader router management.

Validation: Node22.22.3 root, CLI and e2e typechecks; 215 focused tests before the additional native projection case; real Electron capability off/save/reopen/reset passes on Node22. Pi classifier fixtures cover native tokenize/apply-template/completion with normalized probabilities, fresh auth, keyless traffic, endpoint/model/capability changes during auth resolution, malformed/unsupported URLs, cancellation, and global image auth isolation. Root build and explicit CI registry validation pass. No live inference or model-catalog network refresh performed.
