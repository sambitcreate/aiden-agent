# Aiden design-rule lint (UI SDK lessons unit 10)

Built 2026-11-19. `scripts/check-aiden-rules.mjs` (Node, TypeScript AST, no new deps) checks six rules across `git ls-files --cached --others --exclude-standard`. It skips `docs/`, `gui/`, `.memory`, `node_modules`, `dist`, `out` and `build` dirs, and `packages/cli/dist`. It takes about 2 s on the repo. Untracked, non-ignored files are scanned on purpose so new files are checked before they are added. A local scratch file can therefore fail a local run. Docs: `docs/design-guide.md` "Enforced rules".

- Rules: `no-brain-icon`, `text-input-focus-ring`, `no-dialog-dom-sniff`, `network-allowlist`, `no-source-grep-test`, `literal-motion`. Each has a 1–2 line source quote in the script.
- Allowlist `scripts/aiden-rules-allowlist.json`: one JSON object per line, so the reported line is index + 2. An entry with no `max` covers the whole file. With `max`, the file may have at most that many hits. A stale entry fails ("remove it", or "lower max to N"). There is no `--update`, on purpose.
- Inline: `// check-aiden-rules: allow <rule> <why>` on the line or the line above. It fails without a reason.
- `network-allowlist` matches endpoint forms only (`//models.dev`, `openrouter.ai/api/v1/models|benchmarks`, and so on), not prose like "models.dev data". The script's own regexes escape their dots, so they don't match themselves.
- `no-source-grep-test` follows the path argument of `readFile`/`readFileSync` through variables, for-of loops, `.map` callbacks and `read(file)` helper parameters (depth 4, visited set; without the set the search blew up exponentially). A test is flagged only if it also calls `match`/`doesNotMatch`/`includes` or `/re/.test`. The seed holds 97 files (40 renderer, 51 main, 5 scripts, 1 packages/cli). One known false positive is allowlisted with that reason: `scripts/subagent-file-mutator.test.mjs`, which reads a temp `.ts` it wrote.
- `no-brain-icon` also catches lucide's `Lucide*` aliases (`LucideBrainCog`) and renamed imports.
- `network-allowlist` catches any PostHog ingestion host (`*.i.posthog.com`, `app.posthog.com`), but not `mcp.posthog.com` (a user connector). An OpenRouter `/api/v1` base URL is flagged only when the same file also has a `"/models"` or `"/benchmarks"` string; a join made in another file is a known gap.
- `literal-motion` exempts only `--motion-*` / `--ease-*` definitions (a CSS line prefix, or an object key in code). In CSS it blanks `/* */` comments across lines and skips quoted strings, so `url("x/*")` cannot open a comment. In .ts/.tsx it scans only string and template text from the AST, so comments and regexes are never read; a line-based `/*` scan blanked the rest of a file after `"assets/*"`.
- Inline allowances accept JSX `{/* ... */}` and `*` in the reason. For the focus-ring rule they may sit on or above the element's line or its `className` line.
- `text-input-focus-ring` also flags a `focus:shadow-*` class that names the accent. The OpenRouter heuristic also matches `${base}/models` in templates.
- `text-input-focus-ring` allows `border-0`/`border-none`/`ring-0`/`outline-none` on focus, since removing a border cannot add an accent. Non-text `type`s (checkbox, radio and so on) are exempt.
- Unit 1 (layer stack) removed the dialog sniffs while this unit was being built, and the ratchet flagged each one stale. The only `no-dialog-dom-sniff` entry left is `renderer/lib/browser-ui-state.ts`, a geometric occluder selector rather than an Escape sniff.
- Wiring: `check:aiden-rules` script, run in CI's `static` job next to lint. The test is `scripts/check-aiden-rules.test.mjs`, in `test:ci-policy` and the core-git registry lane.
