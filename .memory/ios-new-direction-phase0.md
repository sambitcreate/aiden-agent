# iOS new direction, Phase 0 (quick wins)

Branch `claude/ios-direction-phase0` (2026-11-24). Plan: `docs/plans/ios-new-direction-upgrade-plan.md` on the `ios-new-direction` worktree.

- **Workspace Settings sheet.** `AidenWorkspaceDetailView` presents settings with `.sheet(item:)` over an Identifiable `AidenWorkspaceSettingsPresentation` that carries the request context. The old `isPresented` sheet could render before the context arrived and showed a blank page. `AidenShellUITests.testWorkspaceSettingsOpensWithItsFormEveryTime` opens it repeatedly. Checked on the iPhone Duo inner display at regular width; the fold itself can't be driven from simctl (CoreSimulator has no fold API and Xcode 27.1 ships no Simulator.app).
- **Workspace Git summary.** `aiden-remote-workspaces.ts` fills `git {isRepo, branch?, uncommitted?}` on list, get, create and update from the cached `GitService.info`, all reads under one 1.5 s deadline. A slow or failed read leaves `git` out (unknown, not "not a repo"). `GitService.sharedRead` aborts the shared flight once no consumer remains, so the deadline really abandons the read. No upstream, remote or path is projected; revision unchanged; the host feed stays Git-free.
- **Copy and icons.** The tidied-memory receipt uses `AidenBotMemorySymbol.name` (SD card), never `memorychip`. Usage cards lost their 0.5 pt decorative stroke. "Erase memory" is "Forget all" on desktop, iOS and Android. Bot first-run copy is sentence case everywhere. The iOS Bot composer reads "Message {name}" when nothing holds it (`AidenBotSessionCopy.composerPlaceholder`).
- **Android.** Bot memory description and load-failure strings say "your computer". About 38 other "your Mac" strings remain (save, session, handoff copy). Android's Bot composer still reads "Ask {name}".
- **Known debt left alone.** `AidenDemoResponder` is legacy (`NSLock`, `@unchecked Sendable`). `AidenBotMemoryModel.lane` is a stored Task chain holding `[weak self]` that isn't cancelled on deinit (Swift 5 mode, no isolated deinit).
