# Floating Quick Chat & Attachable Ephemeral Chats — 2026-11-21

Branch: `floating_chat_starter_hotkey`. Archived plan: `docs/plans/completed/floating-chat-starter-plan.md`.

## Summary
- **Floating window & hotkey**: Dedicated `quick-chat.html` + least-privilege preload (`renderer/preload-quick-chat.ts`, `renderer/quick-chat-preload-channels.ts`, `renderer/quick-chat-preload-core.ts` enforcing microphone-only media gates and excluding settings mutation / terminal / browser / screen-capture channels). `main/windows/quick-chat-window.ts` uses `type: "panel"` + `setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true, skipTransformProcessType: true })` on macOS and Wayland-safe positioning (`canPositionFloatingWindow()`) on Linux. Invoked globally via `quickChat.toggle` (`Command+Shift+Space` in `INTRODUCED_DEFAULT_COMMANDS`, registered via Electron `globalShortcut`).
- **Ephemeral chats & attach-to-workspace**: Temporary chats set `ephemeral: true` on `ChatMeta` (classified as `"ephemeral"` surface in `renderer/shared/chat-visibility.ts`), backed by an isolated `noWorkspace` folder under `<userData>/chat-folders/<slug>`. Hidden from `listRegular`, sidebar, search, Inbox, Memory, and Remote; swept on startup if left unsaved across restarts. Promoted in-place via `chats:promoteEphemeral` (Save to Chats) or `chats:attachToWorkspace` (Attach to workspace with scratch-file preflight, collision-safe copy/rollback, Pi `aiden.workspace-attached.v1` boundary, and `resetChatWorkspaceSession`). Zero Remote protocol revision bump.
- **Atomic cross-window stream & approval handoff**: `DesktopLiveStreamAccumulator` + `DesktopHandoffTicketStore` (`quickChat:expandToMain` -> `AidenAppNavigation.openPath` -> `chat:claimHandoff`) + `llmClient.transferGenerationOwner` + `ToolApprovalCoordinator.rebindStreamOwner` + `AskUserQuestionCoordinator.rebindStreamOwner` + `SubagentControlMainV2.rebindChatOwner` + renderer pre-subscribe IPC buffer (`createGenerationStreamBuffer`). `quickChat:handoff-complete` resets the floating window to State 1 without calling `chat:cancel`.
- **Settings, Onboarding & Analytics**: `quickChatDefaultPersistence` (`ephemeral` | `noWorkspace` | `lastWorkspace`) and `quickChatKeepOpenOnBlur` (default `true`) live in Settings → Appearance → Quick Chat (`renderer/components/settings/quick-chat-settings.tsx`). Code-drawn onboarding tile in `renderer/components/onboarding-art/quick-chat-art.tsx`. Privacy-safe events `floating_chat_opened`, `floating_chat_expanded`, and `floating_chat_promoted` capture consent via `captureAnalyticsReporter()` before async lookups.
