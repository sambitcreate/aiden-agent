# CLI schedule consent

Model-facing schedule mutations own a foreground one-shot confirmation even in Full access. Approval captures workspace/folder identity, provider configuration, task state and unchanged arguments; publication rechecks them, expiry and a cancellable private receipt. The generic tool hook exempts only mutations from the exact registered Aiden schedule extension; read calls retain generic Ask-mode approval. Rejected publication rearms the latest persisted enabled schedule even after active-run cancellation advances its revision. Saves prepare and freeze effective values before consent, including defaults and an existing task's retained timezone; the same input is published after approval. Resume displays stored instructions, execution mode and scope with enabled true, and refuses undisplayable instructions before asking. Pause/remove keep compact metadata summaries, and a long old prompt can still be replaced by a shorter one. Specialized feature-owned tasks cannot be edited by the generic model tool. Direct administrative commands are unchanged. Focused built-CLI behavioral coverage lives in packages/cli/tests/parity.test.mjs. Verification and PR status remain in the security remediation plan.
