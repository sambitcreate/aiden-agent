# CLI schedule consent

Model-facing schedule mutations own a foreground one-shot confirmation even in Full access. Approval captures workspace/folder identity, provider configuration, task state and unchanged arguments; publication rechecks them, expiry and a cancellable private receipt. The generic tool hook exempts only mutations from the exact registered Aiden schedule extension; read calls retain generic Ask-mode approval. Rejected publication rearms the latest persisted enabled schedule even after active-run cancellation advances its revision. Large existing prompts remain editable through a bounded metadata summary while the authority snapshot retains the complete task. Direct administrative commands are unchanged. Focused built-CLI behavioral coverage lives in packages/cli/tests/parity.test.mjs. Verification and PR status remain in the security remediation plan.
