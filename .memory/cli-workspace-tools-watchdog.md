# CLI workspace tools and generation watchdog

Issues #536 and #537. Daemon workspace chats now register the shared `buildCodingTools` set through the authority extension instead of Pi's built-ins. Full scheduled inference uses that same set; read-only schedules retain only read_file/list_dir/glob/grep. Bundled native file mutation uses AIDEN_CLI_ENTRY/native/aiden-subagent-file-mutator. Approval summaries and protected-config guards use the canonical names, with legacy hook-name normalization retained for old journals.

The shared file tools enforce workspace containment and `.env` read checks. The CLI additionally supplies a canonical credential-path read fence and checks supplied read/list/grep paths before alias resolution. Actual file/directory kinds preserve public keys, source files, `.gitignore`, `.github` and `.env.example`. This is a path policy, not arbitrary-file private-key content inspection. run_command remains a bounded OS-user shell with a workspace cwd and filtered environment, not a filesystem sandbox. This patch addresses the proposed wiring but leaves #536 open for a decision about shell confinement; #537's fixed five-minute wall-clock abort is replaced.

Both daemon chat and scheduled inference use a five-minute inactivity watchdog refreshed by message_update and tool_execution_start/update/end, with a separate six-hour absolute ceiling. The watchdog is disposed on all exits. Approval expiry and scheduled tool/turn/output budgets are unchanged. Fake-model integration tests cover outside/.env refusal, permitted reads and native writes/edits, a 320-second daemon stream and a 340-second scheduled tool loop. Focused watchdog tests cover silence, each activity event, ceiling and disposal.

Local validation: CLI build and type-check passed; full CLI suite passed 315 with three util-linux TTY skips on macOS. The 44-case daemon lifecycle/approval suite also passed separately. Exact-head CI is recorded in the PR. The old interactive TUI no longer exists; the CLI remains serve-only.

Independent review reproduced id_rsa disclosure in all three daemon/scheduled lanes before the CLI-specific fence. The existing fake-model test now covers that refusal, aliases into credential files/directories, protected aliases to ordinary files, recursive/literal search filtering, safe symlinks and metadata/source/public-key/template controls. Shared desktop reader behavior is unchanged.

The fresh read-only bypass review found a stalled supplied-path stat delaying cancellation before foreground admission. A held-stat behavioral test reproduced it; the CLI precheck and tool invocation now run inside ForegroundReadOperations with prompt abort settlement, bounded admission and the existing five-second search deadline. The new test covers read_file, list_dir and grep cancellation while lookup is pending.
