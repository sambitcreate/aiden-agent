# Android string resources

All user-visible Android copy in composables lives in `android/app/src/main/res/values/strings.xml`, grouped by area comments (shared `action_*` / `state_*` verbs and accessibility states at the top, then Settings, Workspaces, Git, Usage, Files, Bots, Chat, Scheduled, shell, Bot chat tools, notifications).

- Names are `<area>_<purpose>` snake_case (`workspace_home_empty_title`, `chat_composer_send`). Reuse `action_*` (Cancel, Close, Save, Saving…, Retry, Try Again, Delete, …) and `state_*` (Expanded, Collapsed, Selected, Loading, In progress) before adding a new one.
- Composables use `stringResource` / `pluralStringResource`. Copy built inside `semantics {}`, `clearAndSetSemantics {}`, non-composable label lambdas (`AidenSegmentedPillRow`'s `label`), or `CustomAccessibilityAction` is hoisted into a `val` first. Copy built in coroutines or local functions uses `val resources = LocalResources.current` and `resources.getString`. Notifications use `Context.getString`.
- Counts use `<plurals>`; sentences take `%1$s` / `%1$d` arguments rather than concatenation. Small enums and private label helpers carry `@StringRes` ids (`AidenUsageTokenKind`, `AidenBotEditorAccessMode`, `AidenBotChatAccessScope`, `AidenRunInputModeOption`, `AgentRunActivityStatus.titleRes`).
- English values stay byte-identical to what UI tests match with `onNodeWithText`. `chat_progress_steps_done` keeps "steps" and seven placeholders keep "..." with `tools:ignore` for that reason.
- Deliberately still English: ViewModel / controller / state-holder error fallbacks (`AidenChatViewModel`, `AidenWorkspaceHomeViewModel`, `AidenBotsViewModel`, `ComposerVoiceInputController`, `AidenBotGeneratedAvatarModel`, `AidenBotChatToolsModel`, `AidenChatForkErrors`); JVM-tested presentation helpers (`AidenChatRowStatusPresentation`, `aidenRelativeTimestamp`, `aidenFolderCrumbs`, Usage date/inspection labels, `AidenReadAloudProgress.label`, `AidenImageCountBadge.label`, `AidenTurnElapsed`, `AidenMessageTimestamp`); model-layer titles (`AidenWorkspacePermission`, `AidenScheduledTaskFilter`, `AidenApprovalPresentation`, `AidenScheduledTaskPresentation`); protocol values, ids, test tags, and the dev-only `features/bots/prototype`. Moving these needs a resource-id contract change and test updates.
