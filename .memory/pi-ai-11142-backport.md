# pi-ai #11142 backport (2026-10-20)

Pi #11142 (upstream commit caa6967b, "keep the prompt cache across tool changes on Responses", fixes pi#10940) merged to Pi main on 2026-10-20 but is not in any release; npm latest was still 1.3.0. The owner chose to patch it in rather than wait.

- `patches/pi-ai-1.3.0-responses-tool-cache.patch` is a unified diff of pi-ai's compiled `dist` (6 JS files plus 2 `.d.ts`). It was generated by compiling pi v1.3.0 `packages/ai` with `tsc -p tsconfig.build.json` with and without the upstream source diff. The unpatched compile was byte-identical to the published 1.3.0 files, and pi-ai's own suite (1,359 tests) passed on 1.3.0 with the upstream diff applied.
- `scripts/patch-pi-ai-tool-cache.mjs` parses the patch and applies each hunk by exact string replacement. It is idempotent, gated to pi-ai 1.3.0, and all-or-nothing. It runs from root `postinstall`, `build:electron`, `build:electron:production` and the CLI `scripts/build.mjs` (every pi-ai copy the CLI bundle could resolve).
- Behavioral test: `scripts/patch-pi-ai-tool-cache.test.mjs` (in `test:branding`). It captures real OpenAI Responses request payloads across a tool removal and two loads, and checks that pristine 1.3.0 rewrites the prefix while the patched build keeps it.
- Effect: models with `supportsAdditionalTools` and mid-conversation system messages declare all tools in `additional_tools` items and announce removals as text. Tool search and Kimi move the top-level list only once per removal.

On the next Pi bump: if the new release contains caa6967b, delete the patch, the script, its test and the four call sites. Otherwise the version gate fails the install on purpose.

pi-subagents is not an Aiden dependency (native subagents). Its v0.79.2 fixes #2963 and #2968 were reviewed against Aiden: neither applies (tools are rebuilt per generation, and only foreground subagents ship). When background subagents ship (Phase 7B), completion notices need a durable outbox, and each notice should count as delivered only once the parent's turn starts.
