# Focus return and tooltip warm window (UI SDK lessons unit 2, 2026-11-19)

- `renderer/lib/focus-return.ts`: `returnFocus(candidates, { region = "composer", preventScroll = false })`. Candidates are elements or getters, tried in order; `usable` rejects disconnected, `document.body`, `[hidden]`/`[inert]`/`[aria-hidden=true]` ancestors, `:disabled`, and `checkVisibility()` false (happy-dom implements it for `display: none`). A candidate counts only if `activeElement` became it. Fallbacks run only when focus is lost (null, body, disconnected, or inside `options.closing`; review fix, so focus the app moved on purpose stays): `focusRegionEntry(region)` then `[data-app-focus-root]` (the tabIndex -1 root in `root-view.tsx`). Returns the focused element or null (focus untouched). Idea from UI SDK `popup.ts` returnFocus/`take()`; no parent-layer-trigger fallback (Aiden has no popup tree).
- Converted: `Dialog` and `AlertDialog` in `ui.tsx` (shared `useOpener(open)` records the opener in a layout effect, before Radix's FocusScope autofocus; `onCloseAutoFocus` tries the `returnFocus` prop then the opener, and only `preventDefault()`s when something took focus, else Radix default). Compact sidebar cleanup (`closing: sidebarRef.current`), terminal drawer toggle (`closing`: the drawer that held focus) (all `[data-terminal-toggle]` elements as candidates), chat-pane approval card cleanup, subagent pill unmount and tray close (`region: null` there so Radix's default returns to the pill trigger). The 72 `returnFocus=` Dialog call sites (artifacts panel, bot sidebar rows, settings) got the skipping for free.
- Left alone: `environment-panel.tsx` restoreSurfaceFocus already checks inert/aria-hidden; `sidebar/inbox-view.tsx` row refocus; Radix's own default returns for DropdownMenu/Popover/ContextMenu. Chat sidebar delete AlertDialogs fall back opener -> message box -> app root (no neighbour row like `bot-sidebar` has).
- Tooltips: `TooltipProvider` in `ui.tsx` is now a wrapper with `delayDuration={300} skipDelayDuration={400}`; the per-Root `delayDuration={300}` in `ui-primitives.tsx` is gone. Bug shown in test: Radix Tooltip 1.2.12 opens on any non-pointer focus, including programmatic. `returnFocus` keeps a re-entrant depth counter (`isRestoringFocus()`) around `focus()`, and the `Tooltip` trigger's `onFocus` `preventDefault()`s while it is set, which makes Radix's `composeEventHandlers` skip its open. Radix's own focus returns (menus) are not marked, so a menu closing onto a tooltip trigger still shows the hint.
- Tests: `renderer/lib/focus-return.test.tsx` (skip rules, landing check, fallbacks, tooltip stays closed on restored focus but opens on plain focus, a Dialog whose opener unmounted returns to the message box). In `test:command-system` and the registry beside `layer-stack.test.tsx`. Reverting either fix makes the tooltip or Dialog test fail.
