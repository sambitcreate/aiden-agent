**Don't downgrade after a Bot has run on 0.70.0.** Aiden's agent engine is updated to Pi 1.6.0, which stores a Bot's running work in a newer format. Aiden 0.69.0 and earlier, and `aiden serve` builds on Pi 1.5.2, can't open that work afterwards, so going back to an older version isn't supported.

**New default models.** Where you've picked a provider but never saved a model, Aiden now starts on Pi 1.6.0's default for that provider instead of the first model listed: gpt-6.2-sol for OpenAI, Azure and Codex, claude-opus-5-5 for Anthropic, and gemini-4-argon for Google. This also applies to routines and Telegram Bots that name only a provider. If your Azure deployment doesn't offer gpt-6.2-sol, choose a model in Settings → Providers.

**The Agent Slider replaces the Model Pad.**
- One slider in the composer and Quick Chat moves between 3 to 7 stops you set up, each a label with a model and a thinking level. Step with ⌥⌘[ and ⌥⌘], and edit the stops in Settings.
- Thinking level is now kept per chat, and a new chat starts on the last model and level you used.
- Model scores, benchmark charts and measured pace are gone, along with the downloads behind them. models.dev facts and list prices stay in the model hover card.

**Bots on your other Mac look and work like your own.**
- A paired Mac's Bots show their avatar or photo, their last message, an unread dot, and Needs you when they're waiting on you. The list stays live on the Bots page too.
- In a paired Mac's Bot chat you can answer its plans, folder requests and routine ideas, load older messages, and remove a queued message.
- Bots run by `aiden serve` send the same signals, so they show Needs you, Failed and their last reply on your Mac.
- On iPhone and Android, a Bot waiting on you reads "Waiting for you" instead of "Working…" (needs the next phone app build).

**Pick page elements in the Workspace Browser.** Grab an element in the built-in browser and it's attached to your message as a chip with its picture and details.

**Fixes and reliability.**
- A Bot whose MCP server can't be reached skips it instead of waiting on every turn.
- Gemini 4 models from the live catalog get every thinking level, including xhigh.
- Steadier CI and tests: Linux runs pull-request E2E, iOS simulator tests no longer stall, and the Live connection and server-visuals tests are no longer flaky.
