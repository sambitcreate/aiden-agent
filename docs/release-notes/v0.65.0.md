**Aiden On The Go is rebuilt around every machine you've paired.** The iPhone and iPad app now needs iOS 26 or later (it was iOS 18), and it reaches phones through TestFlight.
- **Four tabs:** Inbox, Workspaces, Bots and Search, each with its own back stack. On iPad and other wide screens a sidebar replaces the tab bar.
- **One Inbox for all machines.** Chats from every paired machine appear together, and each machine has a symbol and color you can change.
- **A Machines page** replaces the old connection switcher. Add, rename, hide or remove machines there.
- **Pick the machine** when you start a chat in a workspace or create a Bot.
- **Bots follow their own machine.** Bot pages, routines and notifications now read from the machine the Bot lives on, not whichever machine you last selected.
- **Quieter messages.** A message's time and its Copy and Read Aloud buttons show only when you tap the message. VoiceOver reads the time with the message and offers Copy and Read Aloud as actions.
- Fixes the message box keyboard on iOS 26.5, and adds a way out of Search on iPad.

**Design mode is on by default.** Turn a workspace chat into a design canvas with the Design button, ⇧⌘L or `/design`. The chat sits beside an infinite canvas of pages, notes, shapes, drawings, live workspace pages and images, and Aiden can place and edit pages there. New in this release:
- Comment on any element of a page and send the comments to Aiden as scoped edits.
- Edit a page's words in place. Plain changes go straight into the page's file, and anything else goes to Aiden as a comment.
- Download frames as PNG, PDF or the original file, or present them.
- A side panel with Properties, Layers, the page's code and Tweaks, which include a Dark switch and any controls the page defines.

Design mode is desktop only. To turn it off, set the `AIDEN_DESIGN_MODE` environment variable to `0`. The old Design Studio is gone; Create Images is unchanged.

**Aiden Live can do much more by voice.**
- A floating ribbon above the message box shows when Live is listening, thinking or speaking, with mute and End buttons. Say "bye" to end Live.
- Choose from 30 voices and set speaking speed from 0.75× to 2×, in **Settings → Voice & Speech**.
- Read the open chat, send to it, stop it, find a chat and start a new one by voice. Messages sent this way are labeled **By voice** on desktop and phones.
- Answer the open chat's approvals by saying allow or deny, in 11 languages. This covers Allow once only, for short commands and file edits. Anything that touches secrets, and Always allow, stays tap-only. The switch **Answer approvals by voice** is on by default.
- Let Live move through Aiden's own window, with **Let Live move through Aiden** (on by default). A colored outline shows while it acts, and Esc, a click or typing stops it at once. Approvals, credentials, Bot decisions and other sensitive controls are off limits to it.

Also new:
- **Hooks:** shell commands you approve that run at points in a chat, Bot or routine, such as before a tool runs or when a turn stops. They use the same format as Claude Code hooks, so existing scripts work as they are. A repository's hooks wait for your approval, and hooks are never imported from other tools' settings.
- **Bots can watch Mail or Calendar** and track the work they've accepted in **Open work**, where you can edit, dismiss, undo or stop it. Each routine can use its own model.
- **Bots can ask other Bots for help.** The helper uses its own model, tools and permissions, and its reply is never treated as your consent.
- **Bots can ask for folder access** (Allow once, Always for this folder or Not now) and propose a task plan for one approval, then report progress on a checklist you can stop.
- **Always allow for Bot approvals:** repeated approvals can offer to remember one connected-app action or one website action. The list is under **Allowed without asking** in each Bot's profile, and Remove takes effect on the next call. These work on desktop and phones.
- **Workspace pages** are checked when Aiden saves them, can be run by Aiden (with your approval under Ask first), keep their last five versions with **Earlier versions…**, and can be exported and imported. A **New page** button drafts the request in your message box and never sends it.
- **Settings is reorganized** into 17 pages, with explanations moved behind info hints. **Telegram** now has Connect and Disconnect instead of an Enable switch.
- **Connecting a provider** works the same way in Settings and first-run setup: account, API key or local model. Setup confirms a usable model before you continue.
- **Settings → Storage** measures your whole profile, deletes chats one at a time, and can clear browser caches without signing you out.
- Anonymous usage data now also covers crash reports and counts of which features are used, still with no chats, prompts, replies, file names or paths.
- Opening a long-running chat on a connected computer shows the reply so far, instead of a bare "Thinking".
- A chat's pull request is found even when its local branch pushes under a different name.
- Bot results held during quiet hours wait until quiet hours really end, and a Bot's daily notification budget holds when deliveries overlap.
- Spending charges survive a force quit, and helper summaries count toward the chat's spending limit.
- Environment files transferred to another machine are refused unless Git would ignore them there.
- Copies and forks of a chat without a workspace get their own empty private folder, with Ask first access.
- Web page extraction checks scaled values and keeps complete citations.
- Fixes for browser recording playback on phones, for Bots after a restart, and for Bot browser sessions.
