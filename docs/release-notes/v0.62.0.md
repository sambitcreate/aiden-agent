**Bot databases upgrade one way.** Aiden 0.62.0 moves to Pi 1.4.0, and the first time it opens a Bot's database it upgrades that database. Older versions of Aiden can't open an upgraded Bot database, so installing an earlier release after this one leaves those Bots unreadable.

Also new: redesigned tool approval cards, web page reading with an opt-in extract mode, iMCP as a Mac-only connector, coding follow-through (background jobs, following a pull request until its checks pass, `/until`), retries and Resume when a reply fails or is cut short, New Folder in the workspace folder picker, Bot messages that look sent the moment you press Send, and a model per chat.
