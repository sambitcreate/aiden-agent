**Bot databases upgrade one way.** Aiden 0.62.0 moves to Pi 1.4.0, and the first time it opens a Bot's database it upgrades that database. Older versions of Aiden can't open an upgraded Bot database, so installing an earlier release after this one leaves those Bots unreadable.

Also new: redesigned tool approval cards, Bot hand-off cards that tell you to enter a password or code yourself (the phones need their next build), Paused and Interrupted Bots shown on a paired Mac, web page reading with an opt-in extract mode, iMCP as a Mac-only connector, coding follow-through (background jobs, following a pull request until its checks pass, `/until`), retries and Resume when a reply fails or is cut short, New Folder in the workspace folder picker, Bot messages that look sent the moment you press Send, a model per chat, and Bots that can run a short script of tool calls in one step (each call still asks for approval as usual). In the Aiden CLI, codemode is now on by default; turn it off with `"defaultTools": ["-codemode"]` in its settings.
