**Anonymous usage data.** Aiden 0.64.0 can send anonymous usage counts and crash reports to help fix problems. It never sends chats, prompts, replies, file names, paths, credentials or any text you type. The first launch after updating shows a one-time notice with **OK** and **Turn off**, and nothing is sent until you have seen it. You can change this any time in **Settings → About → Usage data**, where **What's sent** lists every event.

**Chat pictures move into files.** Pictures in chats are now saved as files beside the chats instead of inside them. This is one way: if you go back to an older Aiden, it can't show those pictures and may drop them from chats it saves.

Also new:
- **Chats without a workspace** on the Mac and on phones. Each one gets its own private folder, so files, skills, the terminal and Git still work.
- **Inbox (Beta):** an optional sidebar view that sorts chats by what needs your attention, on the Mac, `aiden serve`, iPhone and Android.
- **Create Images** has an image viewer, History, an All Images library and auto-save.
- **Workspace settings** let you turn skills and connectors off for a single workspace.
- See and stop dev servers the agent left running, on the Mac and on phones.
- Restore a deleted worktree, or start a new chat in main. Phones can start a chat in a new worktree.
- Add local projects to a paired desktop.
- Chat appearance preferences and a default for sending while a reply is running.
- Provider logos wherever a model or provider is listed.
- Skills from installed Claude Code plugins show up on the desktop.
- Phones send pictures with a progress bar and show pictures in a paired Mac's chats and Bots.
- Settings → Bots can let every Bot's routines go ahead without asking.
- Linux draws its own title bar and window controls.
- Clearer messages and recovery steps when a paired computer can't connect.
- `aiden` on the command line is now a headless server (`aiden serve`) with admin commands, including `aiden service install` with local, Tailscale or both.
- Steadier and lighter: lower CPU and GPU use, reliable cleanup of child processes at quit and after a crash, and fixes from a full audit of the server, CLI, Bots, routines, media, devices and the browser.
- **Pictures from the web in chats wait for you.** An image a reply links from another site shows a **Load image** placeholder until you choose to load it.
- Security hardening: phones ask before opening links, unsent phone drafts stay on the device, stricter config and credential file boundaries, credentials kept out of diagnostics, a tighter content security policy, security updates to bundled libraries, and connector and routine approvals checked against current permissions.
