**Security update.** Aiden 0.63.0 moves to Electron 43.8.4, which carries the Node 24.22.1 security fixes.

**Pairing a new phone or Mac now needs Add device open.** A new device's connection request is accepted only while **Settings → Connections → Add device** is open on the computer it connects to, and only if **Accept connection requests** is on. That setting now starts off, including on installs where it was never changed, so turn it on before you pair. Devices that are already paired keep working.

Also new:
- Chats, Bots and routines wait out a provider's usage limit instead of failing, and you can set dollar spending limits per chat, per Bot each month, and per routine run.
- Bots retry a failed routine and pause one that keeps failing. They can follow up on dated promises, set short wake-ups for themselves, and wake when a watched link or script check changes.
- A pill above the chat box shows running subagents.
- Images a reply makes appear at the step that made them.
- Much more of the desktop works from the keyboard. Press ⌘/ to see every key.
- A question that was waiting on you comes back after Aiden quits or crashes, and the Resume card names any approval that was waiting.
- The agent's recommended answer to a question is already selected.
- A clear notice appears when a workspace folder was moved or deleted.
- Chats send fewer built-in tool definitions to the model.
