> **Important — Bot computers now run Linux (Debian 13 + XFCE); existing macOS Bot computers are removed automatically on first launch, and any files or browser sign-ins saved inside them are lost.** Files in each Bot's shared `Computer` folder are kept. You can also run **Remove everything** in Settings → Computers & VMs → Bot computers before updating.

**Bot computers switch to Linux (Debian 13 + XFCE) with shared-by-default computers.**
- Shared by default: Bots share one Linux computer through a FIFO turn queue (one shared desktop and Chromium session with per-Bot `~/bots/<dir>` folders beside `~/Shared`), or you can create dedicated Linux computers in Settings → Computers & VMs or from a Bot's Computer section.
- Smaller and faster to set up: ~3 GB download (Debian 13 arm64 image plus pinned desktop packages) instead of ~20 GB, ~8 GB base disk instead of ~50 GB, 4 GB memory per running computer (2 GB minimum), and up to 4 distinct computers running at once when your Mac has the memory.
- Fully automatic setup with no macOS Accessibility or Screen Recording permission prompts; element control via pinned `cua-driver` 0.38.0 (AT-SPI) works out of the box, and Bot computers now require macOS 14+ on Apple silicon instead of macOS 26+.
- Sign-in on a Bot's computer opens Chromium in the Linux desktop, and `computer_shell` runs as a separate unprivileged `aiden-bot` user whose processes are terminated during sign-in. Every VM starts with `--no-audio-device --no-clipboard-device` via Lume 0.8.0.
- Bots can no longer run Mac-only apps inside a Bot computer (use Computer Use on your Mac with your approval when a Mac app is needed). On first launch, Aiden deletes its own old macOS Bot computers (never touching other Lume/Cua VMs), adds a note to each migrated Bot's memory, and shows one notice in Settings → Computers & VMs with the disk space freed.

**Lume 0.8.0 and `cua-driver` 0.38.0.**
- Upgraded vendored Lume from 0.6.1 to 0.8.0 and `cua-driver` from 0.36.0 to 0.38.0 (macOS universal for Computer Use and Linux arm64 for Bot computers).
- Added clearer CI timing and first-failure reporting and real-desktop Computer Use acceptance checks.
