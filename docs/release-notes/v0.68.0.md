**Aiden Live in the message box, and now on Linux too.**
- With an empty draft, the composer's send button starts Aiden Live on both macOS and Linux — typing turns it right back into Send. The corner pill now appears only while Live is connecting, active, stopping, waiting on an approval, or disconnected.
- Aiden Live starts on Linux (voice and optional screen share through the Wayland portal or X11 source picker) without requiring macOS Computer Use.

**Smarter artifacts, inline visuals and design mode.**
- Workspace artifacts and inline visuals now validate markup against the live renderer, support safer data-backed actions without a shell, keep one artifact version per reply, and automatically place generated `design/` pages onto the canvas (with frame reuse, locked-group handling, and a visual scanner).
- Design mode's canvas toolbars match the chat top bar's button sizing, and **Expand / Minimize canvas** (`⇧⌘\` / `Ctrl+Shift+\`) hides or restores the sidebar so the chat and canvas fill the window.
- Wide inline visuals (`layout: "wide"`) in design mode stay flush with the 16 px left gutter and expand rightwards instead of clipping off the left edge.

**Byte-stable prompt caching across chats, Bots, side calls and `aiden serve`.**
- System prompt prefixes, tool declarations, MCP schemas, AGENTS.md nonces, and compaction boundaries stay byte-stable across turns and compactions, keeping per-turn state (canvas counts, `/visualize`, remote audience notes, browser discovery) in journaled turn notes instead of rewriting the cached head.

**In-app updates for Linux `.deb` and `.rpm` installs.**
- Linux `.deb` and `.rpm` installations can now download and install updates from inside Aiden (Settings → About), and package permissions no longer leave binaries world-writable.

**iOS companion: shell-first onboarding and inline QR pairing.**
- Aiden On The Go opens straight into the app shell with a desktop check and inline frosted QR pairing, with camera-session fallback hardening.

Also new:
- Subagents show one running indicator at a time in the chat instead of duplicating the pill in the top bar.
- Aiden no longer hides itself behind other windows when restoring the Dock icon on macOS launch.
- Faster, more reliable CI startup diagnostics and TestFlight release-doc consistency checks.
