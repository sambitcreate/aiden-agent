**Don't downgrade after a Bot has run on 0.66.0.** Aiden's agent engine is updated to Pi 1.5.2, which moves a Bot's stored conversation to a newer format the first time it writes to it. Aiden 0.65.0 and earlier, and `aiden serve` builds on Pi 1.4.0, can't open a Bot conversation after that, so going back to an older version isn't supported.

**Bots and approvals are simpler and quieter.** One approval mode, one rules page and one approval card now cover workspace chats and Bots alike.
- **One approval mode** in **Settings → Approvals**: Auto, Ask or Never ask. In Auto, the chat's model approves routine actions and asks you about the rest, judging only by what you wrote. New installs start on Auto when a usable model is set up. Existing installs keep their current mode. A workspace can keep its own mode.
- **One rules page** with Always allow, Always ask and Blocked. It fills in from your answers on approval cards and replaces the separate Bot rules and Allowed pages.
- **One approval card** with Allow once, Always allow this tool and Deny. Identical waiting actions share one card, and an action you denied isn't asked about again in the same run.
- **Bot chats are calmer.** Anything waiting on you sits in one Needs-you slot above the message box, and cards leave the chat once they're settled. Tool steps stay hidden unless **Settings → Appearance → Show tool activity** is on.
- **No more "Still working?" cards** on replies you started. A slow reply shows a note in the status line instead. Brief provider hiccups are retried quietly up to three times before a card appears.
- **Fewer notifications.** Heads-ups no longer send banners, Telegram messages or phone alerts. Nothing pings while that Bot's chat is open in front of you. A request still open after 4 hours gets one reminder.
- **Making and managing Bots:** New bot asks only for a name. A Bot's settings are in its side panel's Advanced tab, with one Save. The ••• menu is Pin, Pause and Delete, and Bot messaging is one switch.
- **Bots edit themselves only when you ask.** A Bot can change its own name, look, instructions, check-ins and model, and each change has Undo. A change that would let it do more waits on a card that shows exactly what changes.
- **A Thinking setting for each Bot**, in its Advanced tab under Model. A Bot on a model that can't turn thinking off now uses the nearest level the model supports, so it works again instead of failing every message.
- iPhone and Android show the same approval cards and **Settings → Approvals** when they're paired with a Mac running this version.

**Apps using Aiden: let Claude Code, Codex or another MCP app on the same computer use your chats.** This is off by default. Turn it on in **Settings → Connections → Apps using Aiden** (macOS and Linux desktop).
- **Add an app** gives you a token once, plus ready-to-copy `claude mcp add` and `codex mcp add` commands that keep the token in an environment variable.
- **Read only** apps can list workspaces and read chats. **Supervised** apps can also start a chat, send a message, wait for the reply and stop their own runs.
- **Approvals stay with you.** An app can't answer approvals or reach files, Git, Bots, schedules or settings. Bot chats are out of its reach, and the server listens only on this computer.
- Chats an app started show **Started by** and the app's name. **Revoke** cuts the app off and stops its runs.
- `aiden serve` offers the same through `aiden apps connect "Claude Code"`, `aiden apps list`, `aiden apps revoke` and `aiden apps on|off`. It stays off until your first `connect`.
- Anonymous usage data counts app connections and chats started by apps. It never includes an app's name, its token or your prompts.

**The terminal is easier to work with** (desktop).
- It fills its panel, with no grey frame, and opens at a usable height.
- Select output and choose **Add to chat** to attach it to your message. A new right-click menu has Add to chat, Copy, Paste and Select all.
- A tab shows a dot and the name of the program running in it, and closing a tab while a program runs asks first.
- Full-screen programs no longer flash half-drawn screens. Selection and keyboard shortcuts work better too, and so do links on lines with wide characters.

Also new:
- **Continue in a new chat:** when a chat's folder has been moved or deleted, Aiden copies the chat's history into a new chat in a workspace you pick. The original chat stays readable. This works on desktop, iPhone and Android. On `aiden serve` it can continue only in one of the server's existing workspaces. `aiden serve` now also refuses to work in a missing folder, as the desktop does.
- A tool call you stopped now reads as **stopped** on desktop and phones. It's no longer counted as an issue.
- Dev servers and watchers that Aiden starts only to check its own work stop 20 minutes after the chat goes quiet. The job list says **Stopped after the chat went quiet**. Jobs you asked to keep running aren't affected.
- Aiden calls the computer it runs on a "computer" everywhere. On iPhone, Machines is now **Computers**, and Linux and `aiden serve` users are no longer told about "your Mac".
- On phones, **Commit** stays disabled, and shows the reason, when the Git review doesn't allow committing.
- **Add device** explains when Aiden couldn't read Tailscale.
- **Design mode:** pages Aiden writes appear on the canvas as it writes them, sized for phone, tablet or desktop. This also works when you turn design mode on mid-reply. Aiden can now arrange frames into rows, columns or grids and manage the canvas's pages.
- **Built-in browser** (desktop): the page stays live while its menus are open. A click while your own page loads no longer cancels it. Private tabs start clean every time, and a web page can't fill in an annotation with fake comments.
- If you Steer just as a reply ends, your message is sent next instead of being refused. A message saved just as a reply ended now gets its own answer.
- Followed pull requests update soon after a push or comment and when you return to Aiden. Quiet ones are checked less often.
- Connectors you've signed in to renew their sign-in before it expires. A connector reply in an unexpected shape no longer shows as an error, so Aiden doesn't repeat an action that already happened.
- `aiden serve` chats and scheduled runs use Aiden's own file tools, so the same protections for secrets and outside paths apply. Long replies no longer stop at five minutes while they're still working.
