**Previews for visuals and HTML on iPhone, and SVG Preview on desktop.** You can now view the pages, visuals and SVGs Aiden makes, where before you hit a dead end.
- **On iPhone**, an HTML visual without a snapshot offers **Open interactive**, as it now also does on Android. Workspace `.html` files open on a **Preview** / **Source** switch, and the preview includes unsaved edits. If iOS reclaims a visual while the app is in the background, it reloads.
- **Previews stay offline.** Agent HTML on the phone runs in one web view that blocks `http(s)` and WebSocket traffic, has no WebRTC, and can't open windows or navigate away. A link opens only after you tap it and confirm **Open link?**.
- **SVG code blocks** get **View** on iPhone and an inline **Preview** toggle on desktop. Both draw the SVG on a white card.
- HTML previews on iPhone pick up your Appearance colors, and a page's own styles still win.

**Design mode: a new Tweaks panel.** Pages can offer word fields, a two-way pad, buttons and folders alongside sliders, and number values can be typed.
- **Save version** keeps up to 12 versions of a page's tweaks, and **Show all** lays them out side by side.
- **Send to Aiden** attaches your tweaks to the next message. **Make default** writes them into the page's file, with Undo. **Shuffle**, **Copy** and **Reset tweaks** are there too.
- While you're inside a page that has controls, they float over the canvas.

**Settings fixes.**
- Linux now says "computer" instead of "Mac" in Context & Limits, the approval-mode help, "Allowed on this computer" and a Bot's Full access line. Android's Never ask help says "your computer" too.
- **Telegram → Reset pairing** asks first, and says the next person to message the bot becomes its owner.
- Each Settings page and tab opens at the top, and Back from Settings returns to where you were.

**Pairing and connections.**
- `aiden service install --network tailscale` no longer falls back to a local-network code you didn't ask for. On Linux it offers to run the `tailscale set --operator` step, then retries. The terminal QR code is now narrow enough to scan.
- A Mac paired over the local network (`.local`) reconnects after a brief certificate mix-up on the network instead of stopping. Real identity changes and revoked pairings still stop it.
- Phones reopen file trees cleanly after the server forgets old folder handles, instead of showing stale entries.
- Phones recover from a dropped reply stream without repeating text that's already shown (Remote revision 65).

**Telegram Bots.** Commands, buttons and Stop sent to a Bot in Telegram now go to the Bot's own conversation. A button keeps working across restarts, and photo albums are retried if Aiden is briefly busy.

Also new:
- `aiden serve` is smaller: about 20 fewer bundled files, a much smaller production install, and slightly faster admin commands. It also gives clearer help for unknown commands. The unused terminal-theme control is removed from desktop and phones.
- The desktop app is about 1.85 MB smaller, and a Bot's chat redraws less while it works.
- Choosing a branch for a new worktree chat no longer steals focus from the message box, so Enter sends.
- A navigation in the built-in browser started while a page was still loading no longer reports a false failure or finishes early.
- CI runs faster on pull requests, and several flaky tests are fixed.
