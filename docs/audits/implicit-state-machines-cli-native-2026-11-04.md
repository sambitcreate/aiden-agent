## Exclusions and limits

- Pure command parsing, configuration projection, model availability mapping, static protocol DTOs, synchronous formatting and ordinary loops are not counted as product lifecycle machines. The Foundation Models availability enum and Secret Service exit-code enum describe externally owned conditions; their callers own the real retry/admission lifecycle.
- The CLI imports shared main/services engines directly. Remote pairing/idempotency/streams, Bot capabilities/approvals/session runtime, scheduler, read-marker/triage, workspace gates, and core OAuth are inventoried in the backend report; these rows isolate additional CLI orchestration.
- The source scan includes scripts for discoverability. Build/test harnesses, spike servers, fixture processes, benchmarks, signing commands and CI workflows are ancillary, and were not exhaustively decomposed into machines. O01 is actual runtime support; O02 records the deployment transaction boundary.
- These findings identify state ownership and transitions from source. They do not establish a defect, prove race freedom, or claim exhaustive interleaving coverage. No runtime tests were executed for this documentation-only audit.
