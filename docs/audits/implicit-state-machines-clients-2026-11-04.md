## How to read this inventory

A machine is a retained state plus events that change what actions are permitted or how later events are interpreted. A status union does not make the transition logic explicit: many unions below are updated by independent async callbacks, lifecycle effects, and timers. Pure wire DTOs, configuration, render-only projections, and incidental loop variables are excluded. Stateful stream parsers are included separately as protocol automata. Ordinary UI disclosure/edit/save machines are grouped into families, with implementation anchors, instead of inflating the count for every button.

**V** means the important transition/guard implementation was directly read; **S** means source-level owner/state and available event/method-site triage, without reviewing every transition branch. Neither means runtime verification. Exact source scans are broader than manual review. Names describe the behavioral ownership boundaries; a file can own several machines and a machine can span files. This is a comprehensive discovery inventory, not a proof that every possible transition has been enumerated.
