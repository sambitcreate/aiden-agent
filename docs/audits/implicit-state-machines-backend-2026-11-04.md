No tests executed. Existing test names inspected for key owners; this is inventory, not a bug report or proof of complete transition coverage.

A machine here is state retained across an event, async boundary, process restart, or multi-step protocol which changes which later actions are allowed. A union alone is not a machine. `I` means implicit flag/map/timer or distributed lifecycle; `H` means named states exist but transitions/side effects are distributed. Explicit reducers and transition tables are listed separately. Rows may describe a family of repeated owner instances rather than every object instance. Resource counts/epochs and durable side-effect state are part of the state, not just the displayed status.

Looked for status/phase/state assignments, mutable booleans, pending/active maps, sets, timers, abort controllers, promise queues, lifecycle callbacks, and restart reconciliation. A second const-map pass caught closure-owned machines missed by a class/let-only pass. Source anchors below identify owning implementations; selected complex owners were read in full or substantial blocks, other rows are verified structural/transition scans and should not be mistaken for full path-by-path review. 1. **Generation/turn ownership**: M005–M012 + M019/M020 + M100–M103. Independent flags encode “cancel requested”, “renderer gone”, “IO still settling”, “children still draining” and “chat reusable”. A flat `running` enum would lose essential state; use explicit parallel regions/owned lease transitions.
2. **Bot session/pause/readmission/projection**: M023–M032 + M036 + M048. Paused is a durable user choice, interrupted is harness scheduling, suspending is cleanup, and visible state is a projection. Close callbacks reaching back through the same serialized host can deadlock; current memory and code explicitly warn against this class.
3. **External-effect uncertainty**: M058/M059, M108/M110/M111, M145/M153/M155/M160/M172. Must preserve prepared vs dispatched vs unknown vs terminal; “failed” alone is insufficient and can authorize duplicate effects.
4. **Resource shutdown**: M001/M080/M089/M090/M103/M112/M116–M124/M130. Abort and returned timeout are not proofs process/VM/socket stopped. Parent quit must account for work still being created and fail-closed cleanup.
5. **Consent and credential generation**: M036/M037/M056/M057/M078–M085/M119/M142/M166. Generation fences and point-of-no-return writes deserve explicit transition diagrams and stale-callback tests.
6. **Projection/stream replay**: M013–M017/M032/M060–M064/M070–M072/M104/M137/M140. Multiple mirrors are intentional; distinguish authoritative execution from lossy UI projections and derived status.
